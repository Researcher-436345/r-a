# F09 — Поиск и deep research

**Приоритет:** P1. **Источник ожиданий:** `docs/SERVICES.md` (searchapi ↔ websearch), `services/websearch/README.md` (только ссылки на статьи,
раздел «## Sources», прогресс deep-режима), `searchapi/http.go` (400 на пустое и >20 000 символов, 404 на чужой чат,
события `meta`/`delta`/`sources`/`done`/`error`).
**Код:** `tests/integration/f09_search_test.go`.

Фронт сам придумывает id чата; первое сообщение создаёт чат с заголовком из вопроса. Ответ идёт стримом через
searchapi → websearch → провайдер (fake-llm, который может приложить `url_citation`-аннотации как Perplexity).
Ссылки на списки и оглавления отбрасываются; если ответ цитирует `[n]`, к нему дописывается раздел «## Sources».
