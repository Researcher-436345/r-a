# F11 — Границы доступа

**Приоритет:** P0. **Источник ожиданий:** `backend/README.md` «Guest access» (загрузки приватны, `X-User-Id` отбрасывается),
`docs/SERVICES.md` «Internal», `gateway/handler.go` (CORS: точные origin + credentials; 401 до маршрутизации), `httpx.DecodeJSON`
(1 МБ, неизвестные поля).
**Код:** `tests/integration/f11_access_test.go`.
