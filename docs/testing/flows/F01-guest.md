# F01 — Гость

**Приоритет:** P0. **Источник ожиданий:** `backend/README.md` «Guest access», `docs/SERVER_RECOVERY.md`, `identity/public.go`.
**Код:** `tests/integration/f01_guest_test.go`.

Гость — человек без токена. Ему доступны лента, карточка и PDF публичной статьи, перевод выделения. Всё личное закрыто.

| # | Кейс | Given | When | Then | Статус |
|---|---|---|---|---|---|
| F01-01 | Лента без входа | нет токена | `GET /feed/trending` | 200; категория `cs.AI`, сортировка `new`; у каждой статьи есть `arxiv_id` и `title` | ✅ |
| F01-02 | Лента кешируется | лента запрошена | тот же запрос второй раз | `cached: true` | ✅ |
| F01-03 | Плохие параметры ленты | — | `sort=best`, `limit=51`, `limit=-1`, `category=x` | 400 с `detail` | ✅ |
| F01-04 | Открыть статью из ленты и прочитать PDF | arXiv отдаёт статью `2301.00001` | `POST /papers/arxiv/open`; ждём `/pdf-url` (409 `pdf_processing` → 200); `GET /pdf` | 201 с заголовком/авторами; PDF байт-в-байт равен тому, что отдал arXiv; `Content-Type: application/pdf` | ✅ |
| F01-05 | Повторное открытие не дублирует | статья открыта | `arxiv/open` с тем же id (в виде URL, с версией) | тот же `id` статьи | ✅ |
| F01-06 | `arxiv/open` не трогает библиотеку | вошедший пользователь | `arxiv/open` c `add_to_library: true` | статьи нет в библиотеке | ✅ |
| F01-07 | Неизвестный / битый id | — | `not-an-id`; `2301.99999` (arXiv не знает) | 400; 404 или 422 с понятным `detail` | 🔴 **D-11**: неизвестный id → 500 |
| F01-08 | Перевод выделения гостем | публичная статья открыта | `POST /translate` и `?stream=1` | 200 с `translation`; стрим `delta…done`; провайдеру ушёл текст с инструкцией переводить | ✅ |
| F01-09 | Личное закрыто | гость | библиотека, папки, добавление статьи, заметки, чат, explain, обзор, retry-pdf, find-fulltext, поиск, модели, upload, `/auth/me` | 401 на каждый | ✅ |
| F01-10 | Чужой upload невидим | пользователь загрузил свой PDF | гость: карточка, `/pdf-url`, `/pdf`, перевод | 404 везде | ✅ |
| F01-11 | Подделка `X-User-Id` | есть чужой user id | гость шлёт заголовок `X-User-Id` | 401 | ✅ |
| F01-12 | Мусорный токен | — | `Authorization: Bearer not-a-jwt` на публичный маршрут | 401 | ✅ |

Замечание по F01-10: PDF для загрузки должен отличаться от фикстур arXiv, иначе дедуп по sha256 привяжет
загрузку к публичной статье (это ожидаемое поведение дедупа, см. F03).
