**D-12 `[assumption]`.** После «выйти на всех остальных устройствах» отозванный телефон при следующем открытии
приложения делает silent refresh своей старой cookie. Сервер трактует это как кражу токена (reuse detection)
и отзывает **все** сессии, включая ту, с которой пользователь только что нажал кнопку. Ожидание: reuse detection
срабатывает только на cookie, которые были *ротированы* (`replaced_by`), а не явно отозваны.

**Не проверяется автоматически:** истечение access-токена через 30 минут (нельзя перемотать JWT без изменения
кода); troттлинг verify/reset 10/час (долгий сценарий, идея та же, что F02-12).

**Служебные допущения стенда:** счётчики троттлинга сбрасываются перед каждой регистрацией через Redis, иначе
лимит 5/15 мин на IP остановил бы набор; «просрочить токен» делается правкой `expires_at` в БД.
