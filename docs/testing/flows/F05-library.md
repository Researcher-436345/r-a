# F05 — Библиотека и папки

**Приоритет:** P1. **Источник ожиданий:** `migrations/006_library_folders.sql`, `library/store.go`, `library/http.go`,
`docs/iteration-1.md` («Хочу прочитать», статусы чтения).
**Код:** `tests/integration/f05_library_test.go`.

У каждого пользователя три системные папки: «Хочу прочитать» (`want_to_read` ↔ статус `unread`), «Читаю сейчас»
(`reading` ↔ `reading`), «Другое» (`other` ↔ `read`). Перенос в системную папку меняет статус. Свои папки могут быть
вложенными; при удалении папки её статьи переезжают в «Другое» со статусом `read`.
