# F12 — Деградация

**Приоритет:** P2. **Источник ожиданий:** `docs/HANDOFF.md` §4 (throttle fail-open при недоступном Redis), `docs/PARSER.md` «Ops»
(parse упал → ридер работает, чат по аннотации), `platform/queue.go` (дедуп задач на одну версию), `cmd/worker/main.go`
(остановка воркера — задача возвращается в очередь), `catalog/http.go` (502 при недоступном хранилище).
