# Сценарии

По одному файлу на сценарий из [TEST_PLAN.md §6](../TEST_PLAN.md): `F01-guest.md`, `F02-auth.md`, …

Формат кейса:

```
### F02-07 Повтор отозванной refresh-cookie отзывает все сессии
Given: пользователь вошёл на двух «устройствах», на первом сделан refresh
When:  на первом повторно отправлена старая cookie
Then:  401; `GET /auth/sessions` со второго → 401 (все сессии отозваны)
Ист.:  HANDOFF §4 Auth
```

Пометка `[assumption]` — ожидание не описано в документах и сформулировано нами; требует подтверждения.
