# F08 — Обзор статьи

**Приоритет:** P1. **Источник ожиданий:** `docs/ITERATION_PUSH.md` (обзор в стиле alphaXiv: скелет секций, кэш по `(paper, lang)`,
425/409, `stale`/`force`, дозапрос обрезанного, пустой обрезанный → ошибка без кэша), `docs/PARSER.md` §5, `assistant/summary_http.go`,
`migrations/008_paper_summaries.sql`.
**Код:** `tests/integration/f08_summary_test.go`.

Обзор генерируется лениво при первом открытии вкладки и кэшируется для всех пользователей по паре (статья, язык).
`POST` со `stream=1` отдаёт `delta…done`; готовый кэш отдаётся одним `done`. Пока текст парсится — 425; пока
генерирует кто-то другой — 409. Обрезанный ответ модели (`finish_reason: length`) дописывается продолжением.
