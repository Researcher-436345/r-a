## Запуск и проверка фронтенда

- Основной адрес локального фронтенда проекта: `http://localhost:5180`.
- Изменения интерфейса, включая мобильную версию, проверять сразу на этом фронтенде
  с настоящим API `http://77.91.114.154:8081`. Не подменять API фикстурами,
  моками или тестовыми данными и не создавать отдельный стенд на другом порту
  без явной просьбы пользователя.
- Перед проверкой убедиться, что `:5180` отвечает. Если сервер остановился,
  восстановить его запуск с настоящим API. Существующий рабочий сервер не
  останавливать без необходимости; сохранять его доступность после завершения работы.
- Использовать `--strictPort`, чтобы Vite не переключался незаметно на другой порт.
- Запускать локальный сервер так, чтобы завершение временной команды или сессии
  проверки не останавливало фронтенд. Логи сохранять без паролей и токенов.

Команда запуска из каталога `frontend`:

```bash
VITE_API_URL=/api DEV_API_TARGET=http://77.91.114.154:8081 npm run dev -- --host 127.0.0.1 --port 5180 --strictPort
```

Vite проксирует `/api` к настоящему gateway; настройку API и ожидаемый порт
не менять ради проверки верстки.

```bash

```

`SHA256:+iPInmVRtJ9gZV8fgOJOxbiPB77DBQFqSoSw4JvHuDM`.
