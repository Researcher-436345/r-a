# Проверка интерфейса v3

Исходные экраны: `../examples/v3/v3/*.dc.html`. Основные размеры сверялись
при 1280×720; адаптивная компоновка дополнительно проверялась при ширине 390 px.

Рабочие экраны используют обычный API приложения. Для воспроизводимого сравнения
без backend можно запустить отдельный стенд из каталога `frontend`:

```sh
python3 scripts/v3-fixture-server.py
```

В другом терминале:

```sh
VITE_API_URL=http://127.0.0.1:8089 npm run dev -- --host 127.0.0.1 --port 5174
```

Откройте `http://127.0.0.1:5174`: главная доступна без входа. При открытии
библиотеки или отправке вопроса войдите с любым тестовым email и паролем
от 8 символов. Стенд не восстанавливает сессию после перезагрузки страницы. Данные хранятся только в памяти. Стенд покрывает визуальные
состояния и основные сценарии чата, библиотеки и заметок; он не заменяет
интеграционную проверку импорта и обработки PDF на настоящем backend.
В ридере используется настоящий PDF из ресурсов проекта, поэтому содержимое
страницы и число страниц отличаются от схематичного PDF в HTML-примере.

Каталог компонентов доступен по `/design-system` и загружается отдельным чанком.
Его JSX и CSS можно повторно получить из предоставленного HTML:

```sh
python3 scripts/import-design-system.py
```

Общие компоненты: `LogoMark`, `SleepingCat`, `MetadataLine`, `MessageActions`,
`SegmentedControl`, `ResearchComposer`. Визуальные правила v3 находятся в
`src/shared/styles/v3.css`; стили каталога изолированы в его CSS.

Проверка сборки: `npm run build`.

Проверка гостевого сценария:

1. Главная открывается с лентой; пункта «Активные сессии» нет.
2. Статья из ленты открывается в ридере. Выделение показывает перевод без входа.
3. Библиотека, сохранение статьи, заметки и вопрос ассистенту открывают `/login?next=…`.
4. После тестового входа открывается маршрут из `next`; выход возвращает на главную.
5. Прямой переход на `/settings/sessions` возвращает на главную при выключенном флаге.
6. Включите `VITE_ENABLE_ACTIVE_SESSIONS=true` / `VITE_REQUIRE_LOGIN_ON_ENTRY=true`
   перед запуском Vite, чтобы проверить доступность опционального экрана / прежний вход.
